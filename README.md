#  Project: Number Guessing Game

## Project Description

**Number Guessing Game** is a simple console-based game developed in **C++**. The project was created to practice **random numbers, variables, loops, conditional statements, and user input**.

The computer generates a random number between **1 and 100**, and the player tries to guess it. The game gives hints such as **"Too High"** or **"Too Low"** until the correct number is guessed.

## Programming Language

**C++**

## Concepts Used

- Variables and data types
- User input and output
- `if`, `else if`, and `else`
- `while` loop
- Random number generation
- Comparison operators
- Boolean variables
- Basic problem-solving

## How I Developed This Project

I completed this project in these steps:

1. Planned the idea of the game.
2. Generated a random number between 1 and 100.
3. Added user input for guessing.
4. Compared the guess with the secret number.
5. Added **"Too High"** and **"Too Low"** hints.
6. Used a loop for multiple guesses.
7. Added a condition for the correct guess.
8. Tested and fixed the program.
9. Uploaded the project to GitHub.
