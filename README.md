Project Description
Number Guessing Game is a simple console-based game developed in C++. The project was created to practice random numbers, variables, loops, conditional statements, and user input.
The computer generates a random number between 1 and 100, and the player tries to guess it. The game gives hints such as "Too High" or "Too Low" until the correct number is guessed.

How I Developed This Project
I completed this project in these steps:
Planned the idea of the game.
Generated a random number between 1 and 100.
Added user input for guessing.
Compared the guess with the secret number.
Added "Too High" and "Too Low" hints.
Used a loop for multiple guesses.
Added a condition for the correct guess.
Tested and fixed the program.
